# Online Student Feedback System

A beginner-friendly, front-end web project that lets college students submit anonymous feedback about courses, faculty, and semesters — and view aggregated results on an interactive dashboard.

> **⚠️ Academic Demo:** This project is a front-end demonstration built for educational purposes. It does **not** include real user accounts, authentication, or a secure server. All data is stored in the browser's `localStorage`.

---

```

```

## 🚀 How to Run

No installation, build tools, or servers are needed.

1. **Download / unzip** the project folder.
2. **Open `index.html`** in any modern web browser (Chrome, Firefox, Edge, Safari).
3. Navigate between pages using the top navigation bar.

That's it! The project runs entirely in the browser.

## ✨ Features

| Feature | Description |
|---------|-------------|
| **Feedback Form** | Course, department, semester, faculty, 5-star rating, and comments with validation |
| **Confirmation Modal** | Visual confirmation after successful submission |
| **Dashboard** | Total responses, average rating, department bar chart, recent comments table |
| **Filtering** | Filter feedback by course or department |
| **localStorage** | Data persists across page refreshes |
| **Sample Data** | Pre-loaded fictional feedback so the dashboard is never empty |
| **Responsive Design** | Mobile-friendly layout using CSS Grid, Flexbox, and media queries |

## 🛠️ Technologies

- **HTML5** — Semantic page structure
- **CSS3** — Custom properties, Grid, Flexbox, animations
- **JavaScript (ES6+)** — DOM manipulation, localStorage, event handling
- No external libraries or frameworks

## 📝 Notes

- Clearing your browser's local storage will remove all saved feedback. The sample data will be re-seeded on the next visit.
- This project is suitable for college coursework, mini-projects, or web-development lab assignments.
