ℹ️ About This Project

Project Overview

The Online Student Feedback System is an academic web project that allows college students to submit feedback about their courses, faculty members, and overall academic experience. All submitted data is stored in the browser's localStorage, making it a fully front-end demonstration with no server or database required.

⚠️ Disclaimer: This is a front-end academic demo. It does not include real user accounts, authentication, or a secure back-end server. It is intended solely for educational and project-submission purposes.

Purpose & Objectives

  • Provide a simple, anonymous platform for students to share course feedback.
  • Demonstrate front-end web development skills using HTML, CSS, and JavaScript.
  • Showcase form validation, localStorage persistence, and dynamic DOM rendering.
  • Present aggregated feedback data through an interactive dashboard.
  • Serve as a reusable template for college web-development coursework.

Key Features

📋 Feedback Form

Structured form with course, department, semester, faculty, 5-star rating, and written comments — with real-time validation.

📊 Dashboard

Summary statistics, bar chart of department-wise ratings, and a table of recent feedback entries.

🔍 Filtering

Filter feedback by course or department to focus on the data that matters to you.

💾 Local Storage

All data is persisted in the browser using localStorage, surviving page refreshes.

📱 Responsive

Mobile-friendly layout that adapts to any screen size using CSS Grid and media queries.

🎨 Clean UI

Modern, minimalist design with CSS custom properties for easy theme customisation.

Technologies Used

  • HTML5
  • CSS3
  • JavaScript (ES6+)
  • localStorage API
  • CSS Grid & Flexbox
  • CSS Custom Properties
  • Responsive Design

Limitations

  • Data is stored only in the current browser — clearing browser data erases feedback.
  • No user authentication or role-based access control.
  • No server-side processing or real database.
  • Dashboard charts are basic CSS-based visualisations, not a full charting library.
  • Cannot aggregate feedback across multiple devices or users.

Future Improvements

  • Add a Node.js/Flask back-end with a real database (MySQL, MongoDB).
  • Implement user login and admin panel for faculty/administrators.
  • Use Chart.js or D3.js for richer, interactive visualisations.
  • Add export to CSV/PDF functionality for reports.
  • Enable sentiment analysis on written comments.
  • Deploy to a cloud platform (Heroku, Vercel, Netlify).
